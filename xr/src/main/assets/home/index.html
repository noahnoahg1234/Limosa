Controls in VR

  

    1 finger on empty space: look around. 2 fingers: the left finger moves the left controller, the right finger the right one.
    Tap Hand: Move to switch fingers to Depth (push hands forward and back) or Aim (rotate the controllers).

    LT / RT are the triggers (select), LG / RG the grips (squeeze), X Y A B the face buttons. The circles at the
    bottom are thumbsticks; a quick tap on a stick clicks it. Gyro lets you look around by moving the phone, View: 3D
    switches to side-by-side stereo for a phone headset, ⟲ Center resets the view and hands, the back button leaves VR.
  


  
Settings

  

  
Native games: Limosa XR is an OpenXR runtime. Games built with the standard Khronos OpenXR loader (many recent
    Unity, Unreal and Godot games) can start with it. Games built only for one headset's own loader, old VrApi games, and store
    games that check their license online cannot. Install takes .apk files and split-APK bundles (.apkm, .xapk, .apks); game data (OBB) inside an .xapk is copied when Android allows it.
